# LaudoFlow — USG musculoesquelético

Aplicativo web (arquivo único, funciona offline) para geração de laudos de ultrassonografia
musculoesquelética e apoio às rotinas de exame. Meta: ser referência digital para
ultrassonografistas e demais profissionais habilitados.

- `index.html` — o aplicativo
- `modelos-docx/` — modelos de laudo por segmento (ombro a pé)
- `rotina/` — roteiro e registro da rotina diária de melhoria
- `docs/` — decisões e referências clínicas

> Ferramenta de apoio. O laudo final é de responsabilidade do médico executor.
